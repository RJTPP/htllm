## Scope and Baseline

The SDD was drafted at Phase 1 completion (2026-05-22) covering the initial scaffold: Astro+React shell, ChatProvider abstraction, WebLLM provider, IndexedDB persistence, multi-thread sidebar, model picker, system detection, and basic chat with vision support.

Since then, the entire Phase 2 feature set has been implemented and a comprehensive performance/memory audit has been completed. This represents the largest drift the SDD has experienced — 51 commits, 87 files changed, 16,400+ lines added.

### Data Layer Changes

- **DB_VERSION:** 1 → 3 (v2 added `folders` store, v3 added `byUpdatedAt` and `byThreadCreated` indexes)
- **New stores:** `folders`, `promptTemplates`
- **New indexes:** `threads.byUpdatedAt`, `messages.byThreadCreated` (compound `[threadId, createdAt]`)
- **New queries:** cursor-based `searchMessages`, `IDBKeyRange.bound` for compound index queries
- **New data modules:** `data/folders.ts`, `data/prompt-templates.ts`, `data/reset.ts`

### Provider Layer Changes

- `@mlc-ai/web-llm` imports converted from static to dynamic `import()` (lazy-load)
- `WebLLMProvider.unload()` now terminates the worker and nulls the engine
- `OpenAICompatibleProvider.chat()` now tracks TTFT and decode speed client-side
- `detectReasoning()` added to identify model reasoning capability
- `reasoning_effort` + `enable_thinking` params sent on API calls

### New Hooks

- `useFolders` — folder CRUD state management
- `useModelParams` — thread-level parameter overrides with global defaults

### New Types

- `Folder`, `PromptTemplate`, `ReasoningCapability`, `ReasoningEffort` in `providers/types.ts`
- `Message.reasoning` field for structured API reasoning
- `UsageStats.timeToFirstTokenMs` for API timing
- `Thread.folderId` for folder assignment
- `Thread.modelParams` for per-thread parameter overrides
